Handover

Bringing these frames into Figma

  1. Serve the frames locally from the repo branch design/figma-frames: python3 -m http.server 4610 --directory design
  2. In Figma, run the html.to.design plugin and import each URL with #public,static on the end, for example http://localhost:4610/frames/home.html#public,static, with viewports 1440, 768 and 390 selected. The plugin creates one editable frame per width, with real text layers in Marcellus and Manrope.
  3. Import frames/components.html once at 1440 and turn the specimens into Figma components and variants.
  4. Swap each photo slot for the client’s photographs once received. Swap the logo PNGs for production SVGs when supplied.
